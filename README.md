# Основы веб-разработки

Учебный многостраничный сайт для знакомства с HTML, CSS и базовым JavaScript. Страницы проекта используются как последовательные практические примеры: от структуры HTML-документа и подключения стилей до интерактивного каталога.

## Темы

- семантическая структура HTML-документа;
- общие элементы нескольких страниц;
- подключение CSS, каскад и наследование;
- блочная модель, сетки, отступы и позиционирование;
- изображения, favicon и статические ресурсы;
- базовый JavaScript и обработчики событий;
- интерактивные элементы каталога;
- инструменты разработчика в браузере.

## Структура

- `index.html` — главная страница;
- `author.html` — страница автора;
- `contacts.html` — страница контактов;
- `shop.html` — учебный каталог;
- `styles.css`, `index.css` — стили страниц;
- `script.js` — интерактивное поведение;
- `skins/` — изображения каталога.

## Запуск

Статические страницы можно открыть непосредственно в браузере. Для работы с запросами и JavaScript-модулями проект запускается через локальный статический сервер, например Live Server.
